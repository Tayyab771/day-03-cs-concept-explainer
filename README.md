# CS Concept Explainer: How the Internet Works

A beginner-friendly, single-page website that explains **how the Internet works** using plain English and semantic HTML. Built as a Day 3 portfolio project.

## Topics Covered

- What the Internet is
- IP addresses and DNS
- Servers and clients
- Routers and TCP/IP protocols
- Step-by-step: how a web page loads
- Physical connections (fiber, Wi-Fi, satellite)

## Tech

- Semantic HTML5 only (no CSS, no JavaScript)

## How to View

Open `index.html` in any web browser.
